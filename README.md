# 📊 Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard** created using Microsoft Excel to analyze and visualize sales performance.

## 🖼️ Dashboard Preview

![Sales Analytics Dashboard](dashboard.png)

## 📌 Project Overview

This project provides an interactive dashboard for analyzing sales data and identifying important business trends.

The dashboard includes:

- Total Revenue
- Quantity Sold
- Total Orders
- Average Order Value
- Total Customers
- Monthly Sales Trends
- Sales by Region
- Profit by Region
- Top 5 Customers by Revenue
- Sales vs Cost by Product
- Sales by Item Category
- Quantity Sold by Product
- Orders Over Time
- Sales Target Achievement

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Dashboard
- Data Analysis
- Data Visualization
